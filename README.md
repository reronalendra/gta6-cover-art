Vice Panel Studio — an offline web app that turns your photos into GTA-style poster cover art. Pick a layout (Poster Grid, Hero + Three, Full Bleed, Tilted Snapshots, Nine Panel, Story Stack), a colour grade (Vice Sunset, Neon Night, Teal Pink, Golden Hour, Mono Noir, Purple Haze) applied as a true gradient map, and bold original lettering (Anton title with halftone block, Pacifico subtitle script, Bebas Neue tagline). Drag each photo inside its panel, zoom it, add a badge ribbon and a heat-meter rating, then export a PNG in 1080×1080, 1080×1350, 1920×1080 or 1080×1920. Everything runs locally in the browser — no uploads, no network, no Rockstar artwork or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
